## 2. 찾은 오동작 3건

### 🐞 버그 1 — 입사 예정자의 근속이 **−1년**, 근속수당이 **−30,000원**

**어떻게 나왔나**
사원명부 → [＋ 신규 사원 등록] → 이름 `문가온`, 팀 `영업팀`, 입사일 `2026-09-16`(기본값) → [등록]

**실제 결과**

| 항목 | 값 |
|---|---|
| 명부 근속 | **−1년** |
| 급여 근속수당 | **−30,000원** |
| 9월 실지급액 | 2,312,860원 |

**원인**
입사일(2026-09-16)이 기준일(2026-09-14)보다 **미래**라 `yearsBetween()`이 음수를 반환했습니다.
그 값이 `senior = Math.min(300000, yrs * 30000)` 에 그대로 들어가 **수당이 마이너스**가 됐습니다.

**왜 중요한가**
실습 과제 T1이 정확히 **"2026-09-16 입사자를 등록하라"** 고 시킵니다.
**교육생 전원이 이 화면을 보게 됩니다.**

**수정**
- 공통 헬퍼 `isFuture(날짜)` · `tenure(사원)` 추가 — 근속의 하한을 **0년**으로 막음
- `payroll()`: `const yrs = Math.max(0, yearsBetween(...))`
- 사원명부·사원상세: 입사일이 미래면 `입사예정` 배지 표시

**수정 후 재현 결과**

| 항목 | 수정 전 | 수정 후 |
|---|---|---|
| 근속 | −1년 | **0년** |
| 근속수당 | −30,000원 | **0원** |
| 실지급액 | 2,312,860원 | **2,331,180원** |
| 명부 표시 | — | **`입사예정` 배지** |

### 🐞 버그 2 — 회의실이 2곳인데 화면에는 **"회의실 3곳"**

**어떻게 나왔나**
회의실 예약 화면의 설명 문구를 캡처와 대조

**원인**
10명 회사로 줄이면서 회의실을 3곳 → **2곳**(대회의실·소회의실)으로 바꿨는데, 설명 문구가 하드코딩으로 남아 있었습니다.

**수정**
`'회의실 3곳의...'` → `'회의실 ' + S.rooms.length + '곳의...'` 로 바꿔 **데이터에서 자동으로 세게** 했습니다.
앞으로 회의실을 늘리거나 줄여도 문구가 따라옵니다.

### 🐞 버그 3 — 자산에 사용자를 지정했는데 상태가 **`보관중`** 그대로

**어떻게 나왔나**
자산 대장 → `AS-2026-004` 검색 → [불출/반납] → **사용자만** `문가온` 선택(상태는 안 건드림) → [저장]

**실제 결과**: `사용자=문가온 / 상태=보관중` — **사람이 쓰고 있는데 보관중**인 모순 상태

**원인**
반대 방향 보정(`사용자 없는데 사용중 → 보관중`)만 있고, **정방향 보정이 없었습니다.**
상태 드롭다운의 기본값이 현재 상태(보관중)라, 사용자만 고르면 그대로 저장됐습니다.

**수정**
```
사용자를 지정했는데 상태가 '보관중' 이면  →  '사용중' 으로 자동 변경
```
단, **수리중·폐기대기는 담당자가 의도적으로 고른 상태**이므로 건드리지 않습니다.

**수정 후 재현 결과**: `사용자=문가온 / 상태=사용중` ✅
