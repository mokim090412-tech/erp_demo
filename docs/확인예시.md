## 2. 케이스 A — 승인 가능한 휴가

### 입력값

| 항목 | 값 |
|---|---|
| 신청번호 | `LV-2026-004` |
| 신청자 | 심유나 (HB-0005) |
| 휴가 종류 | 연차 |
| 기간 | 2026-09-21 ~ 2026-09-23 |
| 신청 일수 | **3일** |
| 사유 | 추석 전 휴가(가상) |
| 현재 상태 | **대기** |

### 판정

```
   신청 3일  >  잔여 3일  ?
        3 > 3  →  거짓
                   ↓
              승인 가능 ✅
```

> **"잔여와 신청이 같으면?"** 이 케이스의 핵심입니다.
> **같으면 승인됩니다.** 잔여가 0이 될 뿐이고, 넘어선 건 아닙니다.
> 초과 판정은 `신청 > 잔여` 일 때만 걸립니다.

### 예상 결과

| 항목 | 승인 전 | 승인 후 |
|---|---|---|
| 연차 발생 | 16일 | 16일 (그대로) |
| 연차 사용 | 13일 | **16일** |
| **연차 잔여** | **3일** | **0일** |
| 결재 상태 | 대기 | 승인 |
| 8월 실지급액 | 2,892,050원 | **2,892,050원 (변화 없음)** |
| 9월 실지급액 | 2,767,630원 | **2,767,630원 (변화 없음)** |

> ⚠️ **여기서 놀라는 사람이 많습니다 — 휴가를 3일 승인했는데 급여가 그대로입니다.**
>
> 이유가 **두 겹**입니다. 하나만 알면 다음 실습에서 틀립니다.
>
> **① 연차는 유급휴가입니다.** 쉬어도 기본급은 그대로 나옵니다.
> 기본급을 깎는 건 **결근**과 **무급휴가**뿐입니다.
>
> **② 이 휴가(9/21~9/23)는 "예정 구간"입니다.**
> 근태는 `2026-09-11`까지가 **실적 구간**(출퇴근 기록 있음)이고, 그 뒤는 **예정 구간**입니다.
> 9월 21일은 아직 오지 않은 날이라 원래 연장근로 기록이 없습니다. 그래서 뺄 것도 없습니다.

### ⚠️ 주의 — "연차 승인은 급여를 절대 안 바꾼다"는 틀립니다

**집계 기간 안의 날짜**로 휴가를 승인하면 **실지급액이 줄어들 수 있습니다.**

실제로 해봤습니다 — 오유진 과장에게 9월 1~7일 병가 5일을 승인하니:

| | 승인 전 | 승인 후 |
|---|---|---|
| 9월 실지급액 | 3,622,240원 | **3,541,030원** |

**기본급이 깎인 게 아닙니다.** 그날 하려던 **연장근로가 사라져서 연장수당이 줄어든** 것입니다.

```
   휴가 승인  →  그날 근태가 '휴가'로 바뀜  →  그날 연장근로 기록 사라짐
                                                    ↓
                                         연장수당 ↓  →  실지급액 ↓
```

> **정리하면 이렇습니다.**
>
> | 상황 | 급여 영향 |
> |---|---|
> | 유급휴가(연차·반차·병가·경조사) 승인 | 기본급은 **안 깎임** |
> | 단, 그날이 **실적 구간**(~09-11)이면 | 연장수당이 **줄 수 있음** |
> | 그날이 **예정 구간**(09-14~)이면 | **변화 없음** (케이스 A가 이 경우) |
> | 결근 | 기본급 ÷ 30 × 일수 **공제** |

### 근태 화면에서는 보입니다

승인하면 **근태 현황 9월 21일에 `휴가(예정)` 로 표시됩니다.**
같은 화면 9월 18일을 보면 다른 사람들은 `미입력` 입니다 — 아직 오지 않은 날이라 출퇴근 기록이 없습니다.

**연장수당이 줄어드는 것까지 보려면 9월 11일 이전 날짜**로 휴가를 새로 신청해 승인해 보세요.
그때는 근태가 '휴가'로 바뀌면서 그날 있던 연장근로가 사라지고, 급여대장의 연장수당이 함께 줄어듭니다.

## 3. 케이스 B — 잔여 초과 휴가

### 입력값

| 항목 | 값 |
|---|---|
| 신청번호 | `LV-2026-005` |
| 신청자 | **나선호 (HB-0008)** |
| 휴가 종류 | 연차 |
| 기간 | 2026-10-05 ~ 2026-10-06 |
| 신청 일수 | **2일** |
| 사유 | 신혼여행(가상) |
| 현재 상태 | **대기** |

### 왜 이 사람만 잔여가 적은가

| 항목 | 값 | 근거 |
|---|---|---|
| 입사일 | 2025-07-01 | **전년도 입사자** |
| 발생 | **7.6일** | 15일 × (2025년 재직 184일 ÷ 365) |
| 사용 | 6일 | |
| **잔여** | **1.6일** | 7.6 − 6 |

> 다른 직원들이 16~20일씩 받을 때 이 사람만 **7.6일**입니다.
> 작년 7월에 입사해서 **반년만 근무**했기 때문입니다. 연차는 비례해서 부여됩니다.

### 판정

```
   신청 2일  >  잔여 1.6일  ?
        2 > 1.6  →  참
                     ↓
                초과 ⚠️  (부족분 0.4일)
```

### 예상 결과

| 동작 | 결과 |
|---|---|
| 휴가 결재 화면에서 | 잔여 칸에 **빨간 ⚠ 표시** |
| [승인] 버튼을 누르면 | **경고창**: "잔여 연차(1.6일)보다 신청 일수(2일)가 많습니다" |
| 경고를 무시하고 강행하면 | 연차 잔여 **1.6일 → −0.4일** (음수) |
| 급여 영향 | **없음** (10월 휴가라 8·9월 급여와 무관) |

### 실무에서는 어떻게 하나

잔여가 모자랄 때 선택지는 셋입니다.

| 선택 | 내용 |
|---|---|
| ① 반려 | 잔여 범위 내로 다시 신청받음 (1.6일 → 1.5일 등) |
| ② 일부만 승인 | 1일만 연차, 나머지는 다른 방식 |
| ③ 무급휴가로 전환 | 초과분 0.4일은 **급여에서 공제** |

> **③을 선택하면 급여가 바뀝니다.** 그래서 휴가 결재는 급여 담당자와 연결되어야 합니다.
> 이 앱은 교육용이라 경고만 띄우고 승인 자체는 막지 않습니다. 실제 시스템은 회사 정책에 따라 다릅니다.

## 4. 두 케이스 비교

| | 케이스 A (심유나) | 케이스 B (나선호) |
|---|---|---|
| 신청 일수 | 3일 | 2일 |
| 잔여 | 3일 | 1.6일 |
| 판정식 | 3 > 3 → **거짓** | 2 > 1.6 → **참** |
| 결과 | ✅ 승인 가능 | ⚠️ 초과 경고 |
| 승인 후 잔여 | 0일 | −0.4일 |
| 급여 영향 | 없음 (유급) | 없음 (10월 건) |

> **신청 일수가 더 많은 쪽(3일)이 통과하고, 적은 쪽(2일)이 걸립니다.**
> 중요한 건 신청 일수가 아니라 **그 사람의 잔여**입니다.
> 그래서 결재할 때 신청서만 보면 안 되고, **반드시 잔여를 같이 봐야 합니다.**

## 5. 참고 — 연차에서 안 빠지는 휴가도 있습니다

나선호 사원은 대기 중인 휴가가 **2건**입니다.

| 신청번호 | 종류 | 기간 | 일수 | 연차 차감? |
|---|---|---|---|---|
| (JSON에 미포함) | 경조사 (본인 결혼) | 2026-09-16 ~ 09-18 | 3일 | **아니오** |
| `LV-2026-005` | 연차 (신혼여행) | 2026-10-05 ~ 10-06 | 2일 | **예** |

경조사 3일을 승인해도 **잔여 1.6일은 그대로**입니다. 경조사는 연차와 별개이기 때문입니다.
반면 연차 2일은 잔여에서 빠집니다.

> **같은 "휴가"라도 종류에 따라 차감 여부가 다릅니다.**
> 회사 취업규칙에 어떤 휴가가 유급인지, 연차에서 빼는지가 적혀 있습니다. 그것부터 확인하세요.

## 7. 숫자 한눈에 보기

```
  심유나 HB-0005 · 영업팀 주임 · 2022-11-01 입사 · 가족 1명

  케이스 A  심유나  연차 3일 신청 / 잔여 3일  →  ✅ 승인 가능  →  잔여 0일
```
