# 인사·총무 교육용 가상 업무 앱 — 기획서

> ⚠️ **교육용 가상 자료입니다.**
> 이 문서와 앱에 등장하는 회사·사원·급여·계약·문서는 전부 교육을 위해 처음부터 지어낸 가상의 것입니다.
> 실존 인물·법인·실제 인사정보와 무관하며, 실제 인사·급여·세무 업무에 그대로 사용할 수 없습니다.

---

## 1. 왜 만드는가

인사·총무 담당자 교육에서 반복되는 문제:

- 실제 인사 시스템은 **실명·주민번호·급여**가 들어 있어 교육생에게 열어줄 수 없다.
- 그렇다고 엑셀 예제만 보면 "화면에서 뭘 누르면 뭐가 바뀌는지"의 감각이 안 생긴다.
- 강사가 시연할 때마다 데이터가 오염되어, 다음 기수에 초기 상태로 되돌리기 어렵다.

→ **완전히 가상인 회사 한 곳**을 만들고, 그 회사의 인사·총무 업무를 처음부터 끝까지
돌려볼 수 있는 화면을 제공한다. 언제든 **초기화 버튼 한 번으로 1기 시작 상태**로 되돌린다.

## 2. 가상 회사 설정

| 항목 | 설정값 |
|---|---|
| 상호 | (가상) 한빛상사 주식회사 |
| 업종 | 생활용품 도소매 (가상) |
| 설립 | 2013-03-02 (가상) |
| 임직원 | 10명 (재직 8 · 휴직 1 · 퇴사 1) |
| 조직 | 경영지원본부(경영지원팀) / 사업본부(영업팀·물류팀) |
| 기준일 | **2026-09-14** (앱의 "오늘". 고정) |
| 급여일 | 매월 25일 |
| 연차 기준 | 회계연도 기준 (매년 1/1 일괄 부여) |

**인원을 10명으로 잡은 이유**: 교육생이 표를 스크롤하지 않고 **한 화면에서 전원을 볼 수 있어야** 한다.
50명이면 "어디에 뭐가 있는지" 찾는 데 시간을 쓰고, 정작 배워야 할 업무 흐름은 놓친다.
10명이면 한 사람 한 사람의 사정(입사 1년 미만·전년도 입사·휴직·퇴사)을 강사가 다 설명할 수 있다.

**개인정보 설계 원칙**: 주민등록번호·계좌번호·주소 상세는 **가상으로도 만들지 않는다.**
식별자는 **사번(HB-0001 형식)** 만 사용한다.
반대로 **공제대상가족 수와 8~20세 자녀 수는 넣는다.** 소득세 계산에 반드시 필요하기 때문이다.
"쓸데없는 건 안 갖고, 필요한 건 갖는다"를 데이터 구조로 보여주는 장치다.

## 3. 사용자와 사용 방식

- **강사**: 화면을 띄워 시연 → 교육생 화면과 동일 → "지금 이 버튼을 누르세요" 진행
- **교육생**: 각자 PC에서 같은 파일을 열고 실습 → 과제 탭에서 채점 → 진도 확인

## 4. 모듈 구성

### 4.1 인사 기본
- **사원명부**: 10명 목록, 부서·직급·입사일·재직상태 필터/검색, 상세 카드, 신규 등록·수정
- **조직도**: 본부-팀-인원 트리, 팀별 인원수·평균 근속
- **인사발령**: 발령 이력(입사/승진/전보/퇴사), 발령 등록 시 사원명부에 자동 반영

### 4.2 근태·휴가
- **근태 현황**: 2026년 9월 출퇴근 기록, 지각·조퇴·결근 집계
- **연차 관리**: 입사일 기준 발생일수 계산 → 사용 → 잔여. 계산 근거를 화면에 펼쳐 보여줌
- **휴가 신청/결재**: 신청 → 팀장 승인/반려 → 승인 시 연차 잔여 자동 차감

### 4.3 급여·4대보험 — **사람은 가상, 계산 규칙은 실제**
- **급여대장**: 직급 기준 기본급 + 수당 − 공제 = 실지급액
- **급여명세서**: 명세서 미리보기 / 인쇄 + **「간이세액표 실험」**
  공제대상가족 수와 자녀 수를 바꾸면 소득세가 즉시 다시 계산된다.
  급여가 그대로인데 세금이 얼마나 달라지는지 교육생이 직접 확인하는 것이 이 앱의 핵심 장면.
- **4대보험**: 근로자 부담 / 사업주 부담 분리 집계

**계산 근거** (교육 후 실무로 바로 이어지도록 실제 값을 쓴다)

| 항목 | 근거 |
|---|---|
| 소득세 | 소득세법 시행령 [별표 2] 근로소득 간이세액표 (2026. 2. 27. 개정) — 공식 표 645개 구간을 그대로 탑재 |
| 자녀세액공제 | 같은 별표 비고 3 (1명 20,830원 / 2명 45,830원 / 3명 이상 45,830원 + 초과 1명당 33,330원) |
| 건강보험 7.19% · 장기요양 13.14% | 보건복지부 2026년 확정 고시 |
| 국민연금 9.5% (노사 각 4.75%) | 2026년 · 기준소득월액 상한 637만원 / 하한 40만원 |
| 고용보험 | 근로자 0.9% / 사업주 1.15% (150인 미만 가정) |
| 기본급·수당 체계 | **가상** — 이 교육을 위해 지어낸 것 |

→ 화면 상단에 "**사람·급여는 가상, 계산 규칙은 실제**"를 항상 표시하고,
   실제 급여 지급·세무 신고에 쓰지 말 것을 반복 경고한다.

### 4.4 총무
- **비품 재고**: 품목·수량·안전재고, 입출고 처리, 부족 품목 경고
- **자산 대장**: 노트북·모니터 등 자산번호·사용자·취득일·상태, 반납/불출
- **회의실 예약**: 3개 회의실 주간 예약 현황, 예약 등록·중복 방지
- **문서 대장**: 공문 접수/발송 대장, 보존연한 표시

### 4.5 실습 과제
총 14개. 앱의 현재 상태를 읽어 자동 채점.
예) "2026-09-16자로 영업팀에 신입 1명을 등록하세요" → 명부에 해당 조건 레코드가 있으면 통과.
숫자형 과제는 앱의 현재 데이터로 정답을 다시 계산하므로, 실습으로 데이터가 바뀌면 정답도 함께 바뀐다(의도한 설계).

## 5. 기술 방향

- **단일 HTML 파일 1개** (`인사총무_교육용_가상앱.html`). 설치·서버·인터넷 불필요, 더블클릭 실행.
- 데이터: 앱 내부에 가상 마스터 데이터 내장 + 브라우저 `localStorage`에 작업 내용 저장
- **초기화 버튼**: 저장분을 지우고 1기 시작 상태로 복귀
- **CSV 내보내기**: 명부·근태·급여대장을 엑셀로 열어볼 수 있게 내려받기
- 근태·급여 등 대량 데이터는 **고정 시드 난수**로 생성 → 누가 열어도 항상 같은 값
