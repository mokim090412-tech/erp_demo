## 1. 목적

### 1-1. 왜 만드는가

인사·총무 교육에는 구조적인 문제가 있습니다.

- 실제 인사 시스템은 **실명·주민번호·급여**가 들어 있어 교육생에게 열어줄 수 없습니다.
- 엑셀 예제만 보면 "화면에서 뭘 누르면 뭐가 바뀌는지"의 감각이 생기지 않습니다.
- 강사가 시연할 때마다 데이터가 오염되어, 다음 기수에 초기 상태로 되돌리기 어렵습니다.

→ **완전히 가상인 회사 한 곳**을 만들고, 그 회사의 인사·총무 업무를 처음부터 끝까지 돌려보게 합니다.

### 1-2. 이 앱이 가르치려는 것 (단 하나)

> **인사발령 → 사원명부 → 근태·휴가 → 급여 → 4대보험**
> **앞 칸이 틀리면 뒤 칸은 전부 틀린다.**

모든 기능 결정은 이 문장을 더 선명하게 만드는지로 판단합니다.

### 1-3. 사용자

| 사용자 | 어떻게 쓰나 |
|---|---|
| **강사** | 화면을 띄워 시연. "지금 이 버튼을 누르세요"로 진행 |
| **교육생** | 각자 PC에서 같은 파일을 열고 실습. 과제 탭에서 자동 채점 |

### 1-4. 성공 기준

1. 교육생이 **설치·로그인 없이** 파일을 더블클릭해 3초 안에 실습을 시작한다.
2. 교육생이 **"휴가를 승인했더니 왜 이 숫자가 바뀌었나"** 를 스스로 설명할 수 있다.
3. 기수가 바뀌어도 **같은 숫자**가 나온다. (기준일·난수 고정)
4. 실습 과제 15개 중 **12개 이상**을 교육생 혼자 통과한다.
5. 교육 후 "우리 회사 자료도 이렇게 정리해야겠다"는 반응이 나온다.

## 2. 범위

### 2-1. 하는 것

인사 기본(사원명부·조직도·인사발령) / 근태·휴가(근태 현황·연차 관리·휴가 결재) /
급여·4대보험(급여대장·급여명세서·4대보험) / 총무(비품·자산·회의실·문서) / 실습 과제

### 2-2. 하지 않는 것 — 그리고 이유

| 안 하는 것 | 이유 |
|---|---|
| 실제 인사정보 입력 | 접근 통제·암호화·감사 로그가 없는 교육용 도구 |
| 주민등록번호·계좌번호 | 가상으로도 만들지 않음 (데이터 최소 수집 원칙을 구조로 보여주기 위해) |
| 로그인·권한 관리 | 교육 흐름을 끊음. 모두가 인사담당자 시점 |
| 서버·데이터베이스 | 배포가 어려워짐. 파일 하나로 끝나야 함 |
| 월중 입·퇴사 일할계산 | 이번 범위 밖 (4-2 규칙 2 참고) |
| 연말정산·퇴직금 | 교육 시간(3~4시간)을 넘어섬 |
| 연차 사용 촉진 | 가치는 크지만 법령 기한 검증이 선행되어야 함 ([레퍼런스.md](레퍼런스.md) ③) |

## 4. 동작 규칙

### 4-1. 이번에 새로 정한 규칙 — 전부 구현 완료

#### 규칙 1 — 발령 적용 시점 ✅ 구현됨

**문제였던 것**: 2026-10-01자 승진 발령을 등록하면 **8·9월 급여까지 소급해서 바뀌었습니다.**
(심유나 9월 실지급 2,767,630원 → 3,102,260원) — 지금은 해결되었습니다.

**결정**: **발령일이 지난 발령만 사원명부에 반영합니다.**

| 조건 | 동작 |
|---|---|
| 발령일 ≤ 기준일(2026-09-14) | 사원명부에 **즉시 반영**. 급여도 그 직급으로 계산 |
| 발령일 > 기준일 | **'예정'** 상태. 발령 목록에만 보이고 **명부·급여에 영향 없음** |

- 인사발령 목록에서 예정 건은 **`예정` 배지**로 구분
- 사원명부 상세에 **"예정 발령 1건"** 표시
- 기준일이 발령일을 지나면 자동으로 반영 (이 앱은 기준일 고정이라 실제로는 발생 안 함)

> **왜 이렇게 하나**: 실무에서 발령은 **미리 등록합니다.** 그런데 미리 등록했다고 급여가 먼저 바뀌면 사고입니다.
> "언제부터 적용되는가"가 발령의 핵심이라는 걸 화면이 보여줘야 합니다.

#### 규칙 2 — 휴직자·퇴사자 급여 ✅ 구현됨

| 상태 | 급여대장 | 지급액 | 표시 |
|---|---|---|---|
| 재직 | 포함 | 정상 계산 | — |
| **휴직** | **포함 (0원 행)** | 0원 | **휴직 사유를 행에 표시** (예: 육아휴직) |
| **퇴사** | **제외** | — | 사원명부에서 재직상태 '퇴사'로만 확인 |

> **0원 행을 남기는 이유**: "이 사람은 있는데 급여는 안 나간다"를 눈으로 보여주기 위함입니다.
> 목록에서 빼버리면 휴직자의 존재 자체를 놓칩니다. 4대보험 신고 대상 판단에서 실제로 틀리는 지점입니다.

**범위 밖**: 월중 입·퇴사자의 **일할 계산**은 이번에 넣지 않습니다. 대신 급여대장에 그 사실을 안내 문구로 표시합니다.

#### 규칙 3 — 잔여 초과 승인 ✅ 구현됨

**결정**: **막지 않되, 틀린 상태가 눈에 보이게 합니다.**

| 단계 | 동작 |
|---|---|
| 결재 목록 | 신청 일수 > 잔여 인 건은 잔여 칸에 **빨간 ⚠** |
| [승인] 클릭 | **경고창**: "잔여 연차(1.6일)보다 신청 일수(2일)가 많습니다. 실무라면 반려하거나 무급휴가로 전환해야 합니다." |
| 확인을 누르면 | **그대로 승인.** 잔여가 음수가 됨 |
| 음수 잔여 | 연차 관리 화면에서 **빨간색 + `초과 −0.4일`** 표시 |
| 연차 화면 상단 | 음수 인원이 있으면 **경고 배너**: "잔여 연차가 음수인 사원 N명" |

**판정식** (경계값 주의)

```
   신청 일수 > 잔여 일수  →  초과 (경고)
   신청 일수 = 잔여 일수  →  승인 가능 (잔여가 0이 될 뿐)
```

> **왜 막지 않나**: 차단하면 교육생이 **"틀렸을 때 어떻게 되는지"** 를 못 봅니다.
> 실무에서 이 상황은 실제로 발생하고, 담당자는 반려·일부승인·무급전환 중에서 골라야 합니다.
> 앱은 그 선택의 결과를 보여주는 쪽을 택합니다.

#### 규칙 4 — 근태·급여 기간 범위 ✅ 구현됨

| 구간 | 기간 | 내용 |
|---|---|---|
| **실적 구간** | 2026-08-01 ~ **2026-09-11** | 출퇴근 시각·연장·지각·결근 기록 있음 |
| **예정 구간** | 2026-09-14 ~ **2026-09-30** | 출퇴근 기록 **없음**. 승인된 휴가·공휴일만 표시 |
| 급여 귀속월 | 2026-08, 2026-09 | 그대로 유지 |

- 예정 구간의 근태는 상태가 `미입력` 또는 `휴가(예정)` 중 하나
- 9월 급여는 **실적 구간(09-11)까지의 근태**로 계산 → 급여대장에 기존 안내 문구 유지

> **주의 — 기대와 다를 수 있는 점**
> 근태를 9월 말까지 늘리면 **승인한 휴가가 근태 화면에 보이는 문제**는 해결됩니다.
> 다만 **연장수당이 줄어드는 것**은 예정 구간에서는 볼 수 없습니다. 미래에는 원래 연장근로 기록이 없기 때문입니다.
> 연장수당 감소를 보려면 **09-11 이전 날짜**로 휴가를 신청해 승인해야 합니다.

### 4-2. 이미 구현된 계산 규칙

#### 연차 (회계연도 1/1 기준 일괄 부여)

| 입사 시점 | 발생일수 |
|---|---|
| 당해(2026년) 입사 | 1개월 개근당 1일 (최대 11일) |
| 전년도(2025년) 입사 | 15일 × (전년 재직일수 ÷ 365) |
| 그 이전 입사 | 15일 + (근속연수 − 1) ÷ 2 가산 (상한 25일) |

`잔여 = 발생 − 사용`. **잔여는 저장하지 않고 매번 계산합니다.**
연차·반차만 차감하고, 병가·경조사는 차감하지 않습니다.

#### 휴가가 급여에 미치는 영향 — 정확한 규칙

> 이 부분은 오해하기 쉬워 명시합니다.

| 상황 | 급여 영향 |
|---|---|
| 연차·반차·병가·경조사 승인 (유급) | **기본급은 안 깎임** |
| 단, 그날이 **실적 구간** 안이면 | 그날 있었던 **연장근로가 사라져 연장수당이 줄어듦** |
| 그날이 **예정 구간**이면 | 원래 연장근로 기록이 없으므로 **변화 없음** |
| 결근 | 기본급 ÷ 30 × 결근일수 **공제** |

#### 급여 — 지급

기본급(직급별) + 직책수당(팀장 250,000 / 본부장 450,000) + 근속수당(1년당 30,000, 상한 300,000)
+ 식대 200,000(**비과세**) + 연장근로수당(통상시급 × 1.5 × 연장시간) − 결근공제

**과세대상액 = 지급총액 − 비과세 식대 200,000원**

#### 급여 — 공제 (2026년 실제 요율)

| 항목 | 기준 | 근거 |
|---|---|---|
| 국민연금 4.75% | 기준소득월액(상한 6,370,000 / 하한 400,000, 1천원 미만 절사) | 2026년 |
| 건강보험 3.595% | 과세대상액 | 보건복지부 2026년 확정 (전체 7.19%) |
| 장기요양 13.14% | 건강보험료 | 보건복지부 2026년 확정 |
| 고용보험 0.9% | 과세대상액 | 실업급여 근로자분 |
| **소득세** | **간이세액표 조회** | 소득세법 시행령 [별표 2] (2026. 2. 27. 개정) · 645개 구간 탑재 |
| 자녀세액공제 | 1명 20,830 / 2명 45,830 / 3명 이상 45,830 + 초과 1명당 33,330 | 같은 별표 비고 3 |
| 지방소득세 | 소득세 × 10% | |

**기본급·수당 체계는 가상입니다.** 계산 규칙만 실제입니다.
